TurnItIn is much more tightly tied into D2L then a lot of other external tools. As such, configuration for it is located under the configuration variable browser, under d2l.3rdParty.Turnitin. Here we can see what org units are allowed to use it. Here, we can also add special units, like sandboxes, etc.

In order to do any of this, we need the shared key adm19627

The person who has the admin access on the Turnitin side is Joe Abekah.
