Chromebook Containerless Linux Update Instructions ========================= CONTAINERLESS UPDATE EXPLANATION ========================= Google is migrating to a containerless Linux development environment. This means that rather than running a Linux container in a virtual machine (VM type: Crostini) that runs under ChromeOS, Google is removing the container and just running a Linux virtual machine (VM type: Baguette) inside of ChromeOS. From testing Chromebooks that are on version 144 (Chromebook Settings > About ChromeOS > can see the current Version your Chromebook is on), the containerless Linux development environment update is not out by default. ------------------------- The "Crostini without LXD Containers" flag controls whether or not Linux is running as a container or as a virtual machine (VM). From the testing I have done (the only way I was able to install Linux on an ARM based device was by setting the flag to Disabled. The install also took about 30 minutes which normally takes less than 10 minutes. This is subject to change): Default (subject to change): Linux container (Crostini) with Debian 12 Disabled: Linux container (Crostini) with Debian 12 Enabled: Linux virtual machine (Baguette) with Debian 13 ========================= RUN LINUX AS A CONTAINER OR AS A VIRTUAL MACHINE ========================= If Linux is already installed, it has to be removed first before setting the "Crostini without LXD containers" flag (Terminal app > Developer Settings > next to "Remove Linux development environment", click the Remove button). To set the "Crostini without LXD containers" flag: Open the ChromeOS Chrome browser Go to chrome://flags Search for "containerless" Set "Crostini without LXD containers" flag to desired setting Close Flags window and Chrome browser. Reboot Chromebook. Install Linux the normal way through Chromebook Settings (Chromebook Settings > About ChromeOS > Linux development environment > click Set up button). After installing Linux, you can check the version of Debian that is running from the Terminal app by executing: cat /etc/os-release For Debian 13 with the Linux VM, it is necessary to use the desktop scaling script (short desktop startup scripts won't work). For a video that explains how to use the desktop scaling script: [https://www.youtube.com/watch?v=yK3iwVwwHeg](https://www.youtube.com/watch?v=yK3iwVwwHeg) My most recent "Install Kali Linux On A Chromebook (No Rooting!)" video shows a working example of using the Linux VM: [https://www.youtube.com/watch?v=CkGfgLtm7CU](https://www.youtube.com/watch?v=CkGfgLtm7CU) ------------------------- If Linux is installed as a virtual machine, a false message will be displayed in the Terminal app that states version 143 and up will use the Linux virtual machine by default. After installing Linux on version 143 and 144, The Linux development environment still utilizes containers. The following is the exact message that will be displayed in the Terminal app after installing the Linux VM (VM type: Baguette): NOTICE: To simplify system architecture and maintenance, Crostini has switched by default to a containerless design for new environments starting in ChromeOS version 143 and newer. Function keys can be configured from: Chromebook Settings > Device > Keyboard and inputs If "Treat top-row keys as function keys" is disabled: Search key + 10 keys to the right of Esc = F1-F10 If "Treat top-row keys as function keys" is enabled: 10 keys to the right of Esc = F1-F10 For F11 & F12 keys, from Keyboard and inputs, go to "Customize keyboard keys": Scroll down to the bottom. Click drop-downs next to F11 & F12 and select from the list of key combinations to set the F11 and F12 keys. ========================= DOCUMENTATION ========================= ChromeOS Development Calendar & Release Info: [chromium.org/developers/calendar](https://www.youtube.com/redirect?event=comments&redir_token=QUFFLUhqazhVTG93YnlkaWM1RElUSlo5VFRabjVTR0w1d3xBQ3Jtc0trc3BNcGxBZUJBaTBaakR0cjQzLWoxY1ZCWXdXUl8zcUYwc0FsWEJtSVE5eVNlYmpWVm5iWnAzWHA1NlNjdjZTS0NqbEJUMjF1NkNrNVdTVm1tSTZxZ0ZYTlo3Z055MS1YRU5jUHBUUFRwekR1TEZhNA&q=http%3A%2F%2Fchromium.org%2Fdevelopers%2Fcalendar) ChromeOS Release Schedule (from the ChromeOS Development Calendar & Release Info page.
