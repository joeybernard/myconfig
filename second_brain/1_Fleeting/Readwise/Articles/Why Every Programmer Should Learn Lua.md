## Highlights
- Learning Lua not only makes you fluent in the world’s simplest, usable language but also teaches you lessons that help you to become an experienced, reliable senior programmer who writes better codes in any programming language: ([View Highlight](https://read.readwise.io/read/01kgsmfhk0166dzywj7x7pb1p4))
- Python has lists, tuples, C-like typed arrays, dictionaries, sets, various collection structures, etc. Lua only offers the table data structure that programmers can use for all storage requirements: ([View Highlight](https://read.readwise.io/read/01kgsn1z0yhb2a7z3e0e197pw7))
- Some unique design decisions in Lua encourage you to treat a programming language as a replaceable tool — not as something you should master during your entire career. ([View Highlight](https://read.readwise.io/read/01kgsntc4y1anmdw5t5q1hphh7))
- Lua offers you only one, efficient table data structure, so you’ll have to implement other data structures using it. The table structure is usable as a list and map without writing additional code, but you still have to implement sets, queues, stacks, etc. ([View Highlight](https://read.readwise.io/read/01kgspa7r2ar9c687p9wk4cpm4))
- You can undoubtedly improve your data structures and algorithms knowledge by programming with Lua since it only offers building blocks to construct data structures and algorithms. ([View Highlight](https://read.readwise.io/read/01kgsparhsxqy8qk5x84xaervy))
