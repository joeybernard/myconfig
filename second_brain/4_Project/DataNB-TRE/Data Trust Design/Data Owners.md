Data Owners need to negotiate the life of the data being provided to the data trust. The steps involved include
- what data will be provided
- who will have access to the data
- whether the data can be combined with other data sets
- what research can be done with the data
- how long the data can be stored for
- where the data can be stored
- what happens to the data at the end of the contract

This negotiation process can be handled in two ways:
- [Manual Data Owner Process](Manual%20Data%20Owner%20Process.md)
- [Electronic Data Owner Process](Electronic%20Data%20Owner%20Process.md)
