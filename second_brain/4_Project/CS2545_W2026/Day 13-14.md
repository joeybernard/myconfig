# Probability Theory

- outcome - result of a single trial
- sample space - set of all possible outcomes
- event - some subset of the sample space

- relative frequency probability - number of times an event occurred divided by the total number repeats
- theoretical probability - number of outcomes for the event divided by the total number of outcomes in the sample space

- complement of an event - the set of all outcomes in the sample space NOT included in the event

- conditional probability - probability of an event given that another event has already occurred
	- dependent events
	- independent events

- P(at least one success) = 1 - P(no successes)


- Bayes' Theorem - a statistical technique that allows for the revision of probability estimates based on new information or evidence that allows for more accurate and efficient decision-making in uncertain situations
