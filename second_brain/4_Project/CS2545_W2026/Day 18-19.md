# Hypothesis testing

- involves setting up a null hypothesis and alternative hypothesis based on a claim to be tested and then collecting sample data
	- null hypothesis - a statement of no effect or no change in the population; a statement that the value of a population parameter is equal to a value
	- alternative hypothesis - a complementary statement to the null hypothesis and makes a statement that the population parameter has a value that differs from the null hypothesis

testing claims based on one sample
- Set up a null and alternative hypothesis based on the claim. Identify whether the null or the alternative hypothesis represents the claim.
- Collect relevant sample data to investigate the claim.
- Determine the correct distribution to be used to analyze the hypothesis test (e.g. normal or t-distribution).
- Analyze the sample data to determine if the sample data is consistent with the null hypothesis. This will involve statistical calculations involving what is called a test statistic and a p-value.
- If the sample data is inconsistent with the null hypothesis, then the decision is to "reject the null hypothesis". If the sample data is consistent with the null hypothesis, then the decision is to "fail to reject the null hypothesis".

Types of Error
- Type I error - the researcher rejects the null hypothesis when in fact the null hypothesis is actually true
- Type II error - researcher fails to reject the null hypothesis when the null hypothesis is actually false


p-values
- less than the level of significance, then the decision is to "reject the null hypothesis"
- greater than the level of significance, then the decision is to "fail to reject the null hypothesis"

## Hypothesis testing for two samples
- independent samples - when samples from one population are not related to samples from the other population
- dependent samples - if samples from one population can be paired to samples from the other population
- requirements
	- the samples are random and independent
	- for each sample, the sample sizes are both at least 30, or the underlying populations are known to follow a normal distribution
	- the population standard deviations are unknown; the sample standard deviations are known
	- formula for t-score - page 182

- ttest_ind()
