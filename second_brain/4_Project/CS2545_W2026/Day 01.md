- Data is not very well defined
- Data Science: a field of study that investigates how to collect , manage, and analyze data of all types in order to retrieve meaningful information.
- Made up of
	- domain expertise - data collection
	- computer science - data management
	- mathematics and statistics - data analysis
- Data Science cycle: problem definition -> data collection -> data preparation -> data analysis -> data reporting

Data
- plural of datum
- a single element of information
- types of data
	- quantitative - quantities and amounts
	- qualitative - non-numerical
- quantitative
	- numeric
		- continuous
		- discrete
	- categorical
		- nominal - no ordering
		- ordinal - ordering

Datasets
- made up of a series of items, with each item made up of a number of attributes or characteristics
- structured dataset usually in a tabular form
- unstructured dataset lacks a fixed schema - e.g. free text

Dataset formats
- CSV - items on separate lines, attributes separated by delimiter
- JSON - a set of key/value pairs
- XML - fully structured files
- JSON and XML provide for file meta data fields
