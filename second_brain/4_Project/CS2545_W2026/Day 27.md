# Introduction to Time Series Analysis

Time series analysis allows for the examination of data points collected or recorded at specific time intervals, enabling the identification of trends, patterns, and seasonal variations.

Examples
- forecasting and prediction
- risk management
- anomaly detection
- health care and epidemiology

Workflow
- problem identification/definition
- data gathering
- data cleaning
- model selection
- model evaluation

Definition - any set of data that consists of numerical measurements of the same variable collected and organized according to regular time intervals may be regarded as time series data.

Sequence - an ordered list of numbers
Terms - individual values of the sequence
Time series model - a function, algorithm or method for finding, approximating or predicting the values of a given time series

Time Series Forcasting
- naive or flat forecasting - taking the last value as the best guess for the next value
- simple moving average - the next value is the average of the last few values
- linear regression - can be used if the data fits a linear model
