# Data Cleaning and Preprocessing

- data integration - merging data from multiple sources into a single dataset
- data cleaning - data is assessed for any errors or inconsistencies and appropriate actions are taken to correct them
- data transformation - transforming data into a format that is suitable for further analysis
- data reduction - data reduction may be used to select only the appropriate columns or features needed for analysis
- data discretization - grouping continuous data into categories or ranges
- data sampling - if the data is too large, we may need to sample the data into smaller sets

## Missing Data
- identify the missing data and outliers
	- MCAR (missing completely at random) data - there is no underlying cause of missing data
	- MAR (missing at random) data - missing data is related to other variables but not to any unknown or unmeasured variables
	- MNAR (missing not at random) data - the absence of data depends on observed data but not on unobserved data
- determine the reasons behind missing data and outliers
- determine how to solve missing data issues
- consider the influence of outliers
- use robust statistical methods
- validate the results

## Data Standardization, Transformation and Validation
- normalization - 1NF, 2NF, 3NF (First, Second and Third Normal Form), BCNF (Boyce-Codd Normal Form)
	- apply one of these rule sets to your database
	- a statistical formula to rescale everything between 0 and 1
- transformation changes the data to be easier to analyze
	- log transformation
	- square root transformation
	- exponential transformation
- noisy data
	- data cleaning
	- data smoothing
	- imputation
	- binning
	- data transformation
	- dimensionality reduction
	- ensemble methods
- validation
- data aggregation
- text preprocessing

	- stopwords removal
	- lemmatization and stemming
	- part-of-speech tagging
	- named entity recognition
	- sentiment analysis
	- spell-checking and correction
