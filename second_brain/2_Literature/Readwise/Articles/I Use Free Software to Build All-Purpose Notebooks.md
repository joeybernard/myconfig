## Metadata
- Author: [[Joe Riad]]
- Full Title: I Use Free Software to Build All-Purpose Notebooks
- Category: #articles
- Summary: Joe Riad uses free software called Org in Emacs to create customized virtual notebooks for research and note-taking. These notebooks support multiple languages, code execution, graphics, and exporting to various formats like Jupyter. This setup boosts his productivity by integrating many tools in one place and keeping his work organized and reproducible.

## Highlights
- I therefore needed more features in my notebooks:
  • Support for LaTeX
  • Ability to integrate graphics
  • Ability to work with citation/reference managers
  • Interface to electrical engineering software (simulators for example) ([View Highlight](https://read.readwise.io/read/01kx6py0dsnrym3n4xqp9z08az))
- Having my notebooks integrated into that environment makes it easy to reference specific parts of a notebook, for example, in my work journal. I can add some to-do items in a notebook and have them show up on my calendar as appropriate. I can link to an e-mail message in a notebook and act on it with code. I can do all this stuff and more with zero context switching because it all lives in the same environment and uses the same key bindings. This makes for some truly powerful integrations.
