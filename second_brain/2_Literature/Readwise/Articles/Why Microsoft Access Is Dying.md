## Highlights
- Microsoft Access limits file size to 2GB. ([View Highlight](https://read.readwise.io/read/01kgfpcvbfcmng9gpx8s5ecesw))
- When you hit that ceiling, the database starts throwing "out of memory" errors or refusing to open entirely. ([View Highlight](https://read.readwise.io/read/01kgfpdw5ajdjtym4hbpc92k53))
- Access relies on file locking, which allows multiple people to work at the same time on a Local Area Network (LAN). If a user's [Wi-Fi hiccups](https://www.howtogeek.com/fix-constant-wifi-drops/) while writing to the database, it can corrupt the entire file for everyone else. Access essentially treats a single file as a hot potato, whereas modern databases use a more stable client-server model. ([View Highlight](https://read.readwise.io/read/01kgfpdnkx8wx5h7rta3d274mn))
