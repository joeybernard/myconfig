- Summary: The article suggests new computer science courses that would be valuable but don’t currently exist. ## Highlights
- **CSCI 2100: Unlearning Object-Oriented Programming** 
  Discover how to create and use variables that aren't inside of an object hierarchy. Learn about "functions," which are like methods but more generally useful. Prerequisite: Any course that used the term "abstract base class." ([View Highlight](https://read.readwise.io/read/01kx70hv9geeznqtce95vcrwza))
- **CSCI 3300: Classical Software Studies** 
  Discuss and dissect historically significant products, including VisiCalc, AppleWorks, Robot Odyssey, Zork, and MacPaint. Emphases are on user interface and creativity fostered by hardware limitations. ([View Highlight](https://read.readwise.io/read/01kx70hzav2ffsjpz0cyt5a6wf))
- **CSCI 4020: Writing Fast Code in Slow Languages** 
  Analyze performance at a high level, writing interpreted Python that matches or beats typical C++ code while being less fragile and more fun to work with. ([View Highlight](https://read.readwise.io/read/01kx70j2b0m25d7f9dc375fb3x))
- **CSCI 2170: User Experience of Command Line Tools** 
  An introduction to UX principles as applied to command line programs designed as class projects. Core focus is on output relevance, readability, and minimization. UNIX "ls" tool is a case study in excessive command line switches. ([View Highlight](https://read.readwise.io/read/01kx70j640gwfcjsqakt6jxf5t))
- **PSYC 4410: Obsessions of the Programmer Mind** 
  Identify and understand tangential topics that software developers frequently fixate on: code formatting, taxonomy, type systems, splitting projects into too many files. Includes detailed study of knee-jerk criticism when exposed to unfamiliar systems. ([View Highlight](https://read.readwise.io/read/01kx70jb3mpyvd8kr8vqk4f74a))
