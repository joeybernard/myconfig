## Highlights
- On Linux and macOS, a basic curl command to download a file looks like this:
  curl -O https://example.com/largefile.zip
  And if you want the download to automatically start from where it stopped after an interruption, use this command instead:
  curl -C - -O https://example.com/largefile.zip ([View Highlight](https://read.readwise.io/read/01khnyr6hm94jp6z6az04q4ghm))
- But you can get one of the cleanest weather reports in your terminal using the curl command. It works the same across Linux, macOS, and Windows.
  curl wttr.in
  This command instantly detects your location using your IP address and outputs a formatted forecast to the terminal. ([View Highlight](https://read.readwise.io/read/01khnytcqazj576vdvkg6htaap))
