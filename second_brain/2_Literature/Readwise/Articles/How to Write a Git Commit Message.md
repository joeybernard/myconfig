# How to Write a Git Commit Message

![rw-book-cover](https://cbea.ms/content/images/2021/01/git_commit_2x.png)

## Metadata
- Author: [[cbeams]]
- Full Title: How to Write a Git Commit Message
- Category: #articles
- Summary: Good commit messages explain why a change was made, not just what changed. Start with a short imperative subject line (around 50 chars), leave a blank line, and add a wrapped body if needed. Follow conventions so the history is readable and useful.
- URL: https://chris.beams.io/git-commit
