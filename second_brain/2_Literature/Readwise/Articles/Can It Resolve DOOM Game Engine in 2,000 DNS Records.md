- Category: #articles
- Summary: A developer stored the entire DOOM game using about 2,000 DNS TXT records by splitting and encoding the game files. They created a PowerShell script that fetches these records, reassembles the game in memory, and runs it without writing files to disk. This shows how DNS, meant for domain names, can be misused as a global storage system.
